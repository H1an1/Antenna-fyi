# Greek Myth Profile Roles

This note defines the first 10 Greek myth roles for profile-card background matching. The goal is not strict mythology accuracy; it is a product language for mapping a person's profile signals to an evocative character archetype.

## Matching Principles

- Match the user's visible intent first: what they build, seek, protect, or amplify.
- Prefer roles with strong visual symbols so the card background reads instantly.
- Avoid flattening people into one trait. A profile can have a primary role and 1-2 secondary influences.
- Keep the role names aspirational, not diagnostic.

| --- | --- | --- | --- |

## Example Matching Notes

For a profile, start with these questions:

1. What is the user's active verb? Build, connect, curate, protect, transform, host, navigate, or reveal?
2. What is the user's social mode? Public signal, intimate introductions, community energy, or quiet depth?
3. What visual symbols would make the match understandable without explanation?

For mixed profiles, choose one primary role and use secondary roles only as flavor. For example:

- Hermes + Athena: precise connector with strong product judgment.
- Prometheus + Hermes: frontier builder turning new technology into human networks.
- Apollo + Aphrodite: taste-led curator with social warmth and polish.
- Hades + Persephone: quiet depth, private leverage, and transformation.

### Notes

- If a segment is strongly agent-native, add Prometheus as a secondary influence even when it is not the primary role.
- If a segment is mainly about introductions, ecosystem routing, or industry translation, Hermes should rank high.
- If a segment is mainly about taste, curation, or public expression, Apollo or Aphrodite should rank high.
- If a segment is mainly about private leverage, capital, infrastructure, or serious systems, Hades should rank high.
